# Medcare — Application mobile de téléconsultation

Voir **docs/GUIDE_MODIFICATIONS.md** pour la structure complète, les fichiers modifiables et la mise en route.

Commandes : `npm install` puis `npx expo start`. Configure `src/constants/config.js` (URL du backend) et pour changer le logo animé : `python3 scripts/gif-to-frames.py ton-logo.gif`.
